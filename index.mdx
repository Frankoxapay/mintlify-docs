## OxaPay at a glance

OxaPay is a crypto payment platform for accepting payments, receiving deposits, sending payouts, and swapping digital assets. Integrate these capabilities directly into websites, applications, and commerce platforms with REST APIs and webhooks, or move faster with SDKs, plugins, and automation tools.

## Understand OxaPay API keys

OxaPay separates credentials by capability. Use the key intended for the API you are calling.

<Columns cols={3}>
  <Card title="Merchant API Key" icon="credit-card">
    Used for payment-related API operations such as invoices and static addresses.
  </Card>

  <Card title="Payout API Key" icon="send">
    Used for sending payouts and accessing payout-related operations.
  </Card>

  <Card title="General API Key" icon="key">
    Used for general account-level functionality such as Swap APIs.
  </Card>
</Columns>

<Tip>
  Treat each API key as a sensitive server-side credential and grant access only to the systems that actually need it.
</Tip>
